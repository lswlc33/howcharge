# 咋充 (howcharge)

电池充电/放电曲线预测工具。通过模拟电池的充电和放电过程，可视化展示电流、电压、功率、电量随时间的变化趋势。

## 功能

### 充电模拟
- 支持恒流 (CC) 和恒功率 (CP) 两种充电模式
- 支持高压电池 (4.3V/cell)
- 桩限流/限功率限制
- 涓流充电阶段模拟
- 预算时间内自动优化充电参数（二分搜索）
- 多阶段充电曲线展示

### 放电模拟
- 支持待机功耗和待机电流两种模式
- 基于 OCV-SOC 曲线的电压变化模拟
- 长时间待机时长预测

### 图表交互
- 基于 Chart.js 的交互式曲线图
- 点击图表任意点查看详细参数（电流/电压/功率/电量）
- 预算时间标记线

### 主题
- 浅色 / 深色 / 自动（跟随系统）三种模式切换
- 偏好通过 localStorage 持久化

## 使用

直接在浏览器中打开 `index.html` 即可，无需安装任何依赖。

## 技术栈

- HTML / CSS / JavaScript（单文件，无构建步骤）
- Chart.js 4.4.7（CDN 加载）
